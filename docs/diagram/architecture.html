Postgres 18
the source of truth
  • UUIDv7 ids: history pages by id
  • Full-text search: tsvector + GIN
  • Unread: id past your read pointer
Redis 8
what the replicas share
  • Socket.IO adapter: an event on either replica reaches every socket
  • Presence leases, one Lua script
  • Rate limits · BullMQ queues
SeaweedFS
S3-compatible, private bucket
  • Files, thumbnails, avatars
  • Hour-stable presigned GETs, so browsers cache them
Uploads and images go straight to storage on presigned URLs. The api signs them and checks the result; it never streams file bytes.
